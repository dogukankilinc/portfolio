# Doğukan M. Kılınç - Personal Portfolio

Welcome to my personal portfolio website repository! This site serves as an interactive resume and a showcase of my projects in Artificial Intelligence, Machine Learning, and Electrical/Electronics Engineering.

## Who Am I?
I'm an Electrical and Electronics Engineer specializing in AI and Machine Learning. I currently work at FİGES A.Ş., where I focus on bridging the gap between academic AI research and real-world industrial applications. I'm also pursuing my Master's degree at Bursa Technical University.

My main areas of expertise include:
- **Edge AI & Computer Vision:** Deploying and optimizing deep learning models (like the YOLO family) for real-time inference on NVIDIA Jetson platforms (AGX Orin, TX2).
- **Model-Based Design (MBD):** Designing autonomous systems and utilizing automatic code generation (GPU Coder, TensorRT) within the MATLAB & Simulink ecosystem.
- **TinyML & Embedded Systems:** Bringing machine learning to low-power microcontrollers like the Raspberry Pi Pico.
- **Power & Energy Systems:** Applying AI control strategies (Fuzzy Logic, ANFIS) to fuel cells (PEMFC) and renewable energy systems.

## About This Website
I built this website using plain HTML, CSS, and JavaScript. I wanted to keep it lightweight, fast, and fully customizable without relying on heavy frontend frameworks.

### Key Features
- **Cyberpunk / Matrix Vibe:** A dark, tech-focused design language with custom canvas animations running in the background.
- **Instant Language Toggle:** A custom JavaScript localization script that switches the entire site between English and Turkish seamlessly without reloading the page.
- **Interactive AI Assistant:** A custom slide-out AI chat drawer. The bot is trained on my actual CV, publications, and background, so it can answer visitor questions on my behalf.
- **Responsive & Fast:** Hand-written CSS ensures it looks great on both mobile and desktop screens.

## How to Run Locally
Since it's built with vanilla web technologies, there's no complex build process. 

1. Clone the repository:
```bash
git clone https://github.com/dogukankilinc/portfolio.git
```
2. Navigate to the folder:
```bash
cd portfolio
```
3. Just open `index.html` in your favorite web browser, or use a tool like VS Code Live Server for a better development experience.
